# Heaven Furniture Mart - Atelier Nocturne

A highly bespoke, conversion-focused luxury furniture landing page built for Heaven Furniture Mart. Designed to differentiate the brand from generic e-commerce templates through a cinematic, architectural studio aesthetic.

## 🌟 Premium Features

- **Cinematic Ken Burns Slideshow:** A sweeping, slow-motion hero gallery that crossfades luxury showroom settings.
- **Architectural CAD Overlays:** Subtle, engineering-grade millimeter measurements and crosshairs layered over product images to emphasize precision craftsmanship.
- **Interactive Commission Blueprint (Cost Estimator):** A dynamic pricing engine that instantly calculates bespoke furniture investments based on room type, scale, and material finish, outputting directly to WhatsApp.
- **Anatomy X-Ray Simulator:** A stylized grayscale technical breakdown that peels back the layers of furniture to reveal the kiln-dried frames and high-density cores inside.
- **Showroom Lighting Simulator:** A tactile day/night mode toggle that realistically alters the hero environment's ambient light.
- **Deep Technical Material Metrics:** An advanced material library displaying exact timber densities, moisture content percentages, and Martindale rub counts for discerning buyers.

## 🛠 Tech Stack

- **React + TypeScript:** Type-safe, component-driven architecture.
- **Framer Motion:** Cinematic entrance animations, staggered reveals, and magnetic button physics.
- **Vite:** Lightning-fast HMR and optimized production builds.
- **Vanilla CSS:** Entirely bespoke styling framework tailored specifically to the "Atelier Nocturne" design language (Charcoal, Teal, Parchment, and Brass). No generic utility frameworks.

## 🚀 Getting Started

1. Install dependencies:
   ```bash
   pnpm install
   ```
2. Start the development server:
   ```bash
   pnpm dev
   ```
3. Visit `http://localhost:3001` (or your active port) to view the studio.
